  1. ICECTE
    Vision-Guided Real-Time Obstacle Avoidance and Path Planning Using a Single Overhead Camera
    Arif Zakaria, Md. Woahidur Rahman, Md. Fahim, and 1 more author
    In 2026 5th International Conference on Electrical, Computer & Telecommunication Engineering (ICECTE), 2026
    Abs DOI Bib HTML

    This paper presents a real-time obstacle avoidance and path planning system for a mobile robot using a single overhead camera. Localization is achieved using ArUco markers, enabling accurate pose estimations of the robot and dynamic target locations. Obstacles are segmented in real-time using the YOLOv11-seg model, giving a binary occupancy grid for navigation. The A* algorithm determines the shortest collision-free path on this grid, and a Proportional–Integral–Derivative (PID) controller drives the robot along the path by transmitting commands via User Datagram Protocol (UDP). The system allows replanning of paths in real time when the position of target or obstacle changes, and automatically sequences multiple targets based on proximity. Experimental data support robust and low-latency navigation in complex environments. All the codes used here are open source and the setup is easily reproducible, enabling widespread accessibility within research and educational robotics communities.
